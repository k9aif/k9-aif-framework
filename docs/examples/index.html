Live applications

Complete applications on K9-AIF, running in public. Try them, then read the code.

LiveFlagship

DAS: Defense Acquisition System

AI agents prepare the defense acquisition package; a person decides at every gate. A Service capability requirement goes from the sponsor's documents through Service validation, the Materiel Development Decision, Milestone A and the System Requirements Review, following the process in force today.

  • A versioned process model: every stage and gate cites its policy source
  • Every section screened by k9x Shield and Granite Guardian; red-team documents included
  • A verdict per criterion, with the score computed in code; an independent grader from a different model family
  • Every gate decided by a person in K9X HIL; undecided gates fail closed
  • A sample AWS GovCloud deployment guideline

LiveAssistant

K9Chat

A governed chat assistant, open source, on your own models. It answers from a grounded knowledge base, gives each visitor their own document projects, and protects the GPU it runs on.

  • Every message through a rate limit, k9x Shield, Guardian and the router
  • Knowledge grounding and per-visitor Projects with their own documents
  • A concurrency and GPU-thermal admission guard
  • An LLM-as-judge toggle, streaming, and an Ask API for other applications

Where to start

A path from small to complete:

  1. Weather Assist: the smallest app, and how K9-AIF wraps an agent framework you already use.
  2. Zero Trust Execution: how every agent action is governed before it runs.
  3. ACME Support Center: one architecture, several reasoning strategies, chosen by configuration.
  4. RFP Analyzer: retrieval over a large document.
  5. DAS: a complete application with a process model, screening, grading and human gates. Watch the 7-minute walkthrough, then run it.

How to run them

Each example's README has its own setup. From the root of the k9-aif-framework repository:

./run_acme_support_center.sh       # ACME Support Center
bash build.sh && bash run_eoc_pod.sh   # Enterprise Insurance Ops Center (Podman)

DAS and K9Chat live in their own repositories: k9aif/dow-k9x (with k9aif/k9x-hil for the gates) and k9aif/examples. Their READMEs list the services and settings.

The examples are practical demonstrations, not finished products: they show how K9-AIF structures governed, modular AI applications that you can extend for your own needs.
